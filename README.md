# jeton

The public web pages for **Jeton**, an Android game app. No application code
lives here — only what has to be reachable by a URL.

https://fatihbarackilic.github.io/jeton/

- `privacy.html` — privacy policy, Turkish
- `privacy-en.html` — privacy policy, English
- `index.html` — landing page
- `style.css` — shared stylesheet

Served by GitHub Pages from `main` / `(root)`; a push republishes. Files are
flat on purpose, because the path is part of the published URL.

Why these pages are not in the app's own repo, what must stay in step with the
app, and which URL Play Console points at: see the README there.
